# TechVision - Modern Company Profile Website

A stunning, responsive company profile website built with modern web technologies. Features a beautiful Glassmorphism design, smooth animations, and a dark/light theme.

## 🌟 Features

- **Modern Design**
  - Glassmorphism UI elements
  - Responsive layout for all devices
  - Dark/Light theme support
  - Smooth animations and transitions

- **Technical Features**
  - Built with React + Vite
  - TypeScript for type safety
  - Tailwind CSS for styling
  - Framer Motion for animations
  - React Router for navigation
  - Parallax scrolling effects
  - Responsive navigation with mobile menu

## 🛠️ Technologies Used

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Type Safety**: TypeScript
- **Routing**: React Router DOM

## 📱 Responsive Design

The website is fully responsive and optimized for:
- Mobile devices (320px and up)
- Tablets (768px and up)
- Desktops (1024px and up)
- Large screens (1280px and up)

## 🎨 Theme Support

- Dynamic theme switching between Dark and Light modes
- Persistent theme preference using localStorage
- Smooth transition effects between themes
- Maintained Glassmorphism effects in both themes

## 💻 Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
